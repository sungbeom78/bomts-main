메일 링크는 HTTP 관리 포털에서 인증하지 않고 Mailu의 직접 HTTPS 포트로 이동합니다. 주소에 :3001이 남아 있으면 사용하지 않습니다.

계정별 자동 전달

  1. 메일 관리에서 대상 사용자를 엽니다.
  2. Auto-forward를 켜고 Destination에 여러 주소를 쉼표로 입력합니다.
  3. Mailbox에도 남기려면 Keep a copy of the emails를 켭니다.
  4. 저장 후 외부에서 시험 메일 한 건을 보내 원본 Mailbox와 전달 대상 모두를 확인합니다.

Naver 등 외부 계정 가져오기

  1. 외부 서비스에서 POP3/IMAP 사용과 앱 비밀번호를 활성화합니다.
  2. 메일 관리 → Fetched accounts에서 서버·포트·TLS·사용자 이름을 등록합니다.
  3. 가져온 메일을 받을 BOMTS 사용자를 지정하고 원본 서버 보존 여부를 선택합니다.

외부 메일 앱 연결

서버는 mail.bomts.net, 사용자 이름은 전체 이메일 주소입니다. IMAP 993, POP3 995, SMTP 465(SSL/TLS) 또는 587(STARTTLS)을 사용합니다.
