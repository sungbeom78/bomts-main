Founder

안숭범 (Sungbeom Ahn)

18년 이상 데이터 엔지니어링, DW/ETL 및 기업 데이터 시스템 구축 업무를 수행했습니다. Informatica, Hadoop, SQL 기반 데이터 플랫폼과 데이터 처리 시스템을 주로 다뤘습니다.
