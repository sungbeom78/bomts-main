# BOMTS 전용 규칙

## 서브모듈 변경 승인 규칙

`dev-process-framework`와 `glossary`는 AGENTS.md 0번의 절대 보호 구역이다. 이 프로젝트에서는 승인을 받더라도 서브모듈 내부 파일, 커밋, 브랜치, 태그 또는 원격 저장소를 수정하지 않는다. 필요한 변경은 `dev-process/local/upstream-requests.md`에 기록하고 소유자가 원본 저장소에서 처리한다.

소유자가 배포한 새 버전을 부모 저장소에 반영하는 다음 작업은 수행 전에 사용자에게 대상 버전을 제시하고 명시적 승인을 받는다.

- 공식 업데이트 도구를 이용한 부모 저장소의 서브모듈 commit 포인터 변경
- 서브모듈 원격 URL 또는 `.gitmodules` 변경

상태 확인, 문서 읽기, 검증 실행 등 비변경 작업은 별도 승인 없이 수행할 수 있다. 프로젝트별 확장은 `dev-process/local/`에만 구현한다.
