이용 흐름

방문자는 소개에서 제품과 연락으로 이동합니다

  1. 홈핵심 메시지
  2. 소개경력과 방향
  3. 제품제공 가치
  4. 연락이메일 연결
  5. 정책개인정보·약관
상단 탐색과 본문 링크는 같은 공개 페이지 집합으로 연결됩니다.
처음 방문한 사람은 홈에서 BOMTS의 목적을 확인하고 소개와 제품 페이지로 이동합니다. 연락 페이지는 이메일 링크를 제공하고 개인정보와 이용약관 페이지는 사이트의 처리 범위를 설명합니다.

현재 사이트는 방문자 입력을 서버로 전송하는 기능이 없습니다. 이메일 링크를 누르면 방문자의 메일 앱이 열립니다. 향후 폼이나 로그인을 추가하면 저장 데이터와 보존 기간, 삭제 절차를 먼저 설계해야 합니다.
