BOMTS
이 매뉴얼은 공개 저장소 독자를 위한 안내입니다. 제품 페이지와 논리 구조, 로컬 개발 절차만 다룹니다. 실제 배포 환경과 운영 인수인계 자료는 Private 인프라 저장소에서 관리합니다.

문의 링크는 방문자의 메일 앱을 열며 이 저장소의 사이트가 입력 내용을 저장하지 않습니다.
웹사이트는 정적 페이지 모음입니다. 소개와 제품 방향을 읽고 공개 이메일 주소로 연락할 수 있습니다. 서버 측 문의 폼과 로그인 기능이 없으므로 방문자가 입력한 업무 데이터를 저장하지 않습니다.
