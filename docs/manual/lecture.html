강의 QR 덱

프로젝터에 QR 자료를 한 장씩 크게 띄우고, 같은 주소를 수강생과 공유합니다.

LECTURE
이 장은 lecture.bomts.net의 사용법과 확장 방법을 설명합니다. 강사는 키보드나 화면 클릭으로 QR을 한 장씩 넘기고 수강생은 휴대전화 카메라 또는 QR 이미지 클릭으로 자료를 엽니다. 세 번째 화면에서는 공공데이터 탐색, 데이터 정제, 대시보드 제작용 Gem을 바로 선택합니다.

  4. 로컬 실행파일을 브라우저로 열기
서버 URL에서는 HTML이 실행되지 않고 항상 첨부 파일로 내려옵니다.
둘째 화면의 QR과 아래 링크는 같은 HTML 파일을 다운로드합니다. 응답은 attachment와 application/octet-stream으로 강제해 서버 주소에서 스크립트가 실행되지 않습니다. 다운로드 폴더에 저장된 파일을 브라우저로 열면 로컬 저장소도 서버 페이지와 분리됩니다.

프롬프트 카드 URL에는 Nginx 다운로드 전용 규칙을 적용합니다. Gem QR 세 개는 PDF의 링크 주석과 QR 디코딩 결과를 대조한 뒤 별도 PNG로 생성합니다. 화면의 QR과 텍스트 링크는 같은 URL을 사용해 서로 어긋나지 않게 검사합니다.

장애 대응

QR·화면·공개 경로를 순서대로 나누어 확인합니다

증상원인 후보조치
QR 인식 실패화면 밝기·QR 이미지 오류대상 URL과 QR 디코딩 결과 대조
HTML이 화면에서 열림attachment 규칙 미적용Content-Disposition·Content-Type 확인
Gem 접근 불가Google 로그인·공유 권한시크릿 창에서 원본 링크 시험
공개 404·502DNS·Tunnel ingress·컨테이너로컬 Host 응답부터 단계별 확인
Gem 로그인·권한 오류는 강의 페이지가 아니라 Google 공유 설정에서 확인합니다.
QR이 읽히지 않으면 공개 URL과 디코딩 결과를 대조합니다. 직접 URL에서 HTML 화면이 보인다면 다운로드 전용 헤더가 빠진 것입니다. Gem이 열리지 않으면 Google 로그인과 공유 권한을 시크릿 창에서 확인한 뒤 공개 경로 장애와 분리합니다.
